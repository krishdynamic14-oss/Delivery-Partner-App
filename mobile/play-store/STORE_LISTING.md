# Dynamic Bazar Delivery - Play Store Listing Draft

## App Name

Dynamic Bazar Delivery

## Short Description

Delivery partner app for Dynamic Bazar order, COD, stock proof, and route operations.

## Full Description

Dynamic Bazar Delivery is an operations app for Dynamic Bazar delivery partners and admins.

Delivery partners can view assigned orders, plan delivery dates, call customers through the configured calling flow, confirm deliveries with OTP and proof photos, report failed or RTO orders, submit COD settlements, capture daily stock proof, and sync field updates with the company system.

Admins can monitor orders, review partner activity, approve COD settlements, assign orders, check submitted stock proof photos, and view partner location updates where enabled.

Key features:

- Partner and admin login from one app
- Assigned order list with planned delivery date filters
- Order detail view with delivery, failed/RTO, COD, and proof workflows
- Customer OTP based delivery confirmation
- Proof photo capture and upload
- COD tracking and settlement submission
- Daily stock proof photo capture
- Push notifications for assigned orders and reminders
- Location update support while the app is open
- Offline queue and manual sync support

This app is intended for Dynamic Bazar's internal delivery operations and authorized users only.
